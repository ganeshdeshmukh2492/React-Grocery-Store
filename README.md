FreshMart Grocery

FreshMart Grocery is a modern and responsive e-commerce grocery website developed using React, Tailwind CSS, and React Icons. The platform is designed to make online grocery shopping simple, fast, and convenient for users.

Customers can browse a wide range of fresh products including fruits, vegetables, dairy products, beverages, snacks, and daily essentials, and place orders easily through an interactive user interface.

Features
Responsive design for mobile, tablet, and desktop
Browse fresh fruits and vegetables
Order daily grocery essentials
Modern UI with React Icons
Category-based product sections
Smooth navigation
Shopping cart/order section
Clean and user-friendly design
Technologies Used
React
Tailwind CSS
React Icons
JavaScript
HTML5
CSS3
Purpose

This project was built to practice frontend development skills and create a real-world grocery shopping website with modern design and functionality.
